# 试用期：期限、工资与解除

> **依据**：《劳动合同法》第 19、20、21、37、39 条。本文件为独立编写。

## 一、法定期限上限

| 劳动合同期限 | 试用期上限 |
|---|---|
| 3 个月以下 | **不得约定** |
| 3 个月以上不满 1 年 | 1 个月 |
| 1 年以上不满 3 年 | 2 个月 |
| 3 年以上固定期限或无固定期限 | 6 个月 |
| 以完成一定工作任务为期限 | **不得约定** |
| 非全日制用工 | **不得约定** |

**同一用人单位与同一劳动者只能约定一次试用期。** 岗位调整、合同续订均不得再次约定。

**超出上限的后果**：超期部分不成立。若约定的试用期已实际履行，该超期期间应按转正后的标准补足工资差额。

## 二、试用期工资底线

不得低于本单位相同岗位最低档工资，或劳动合同约定工资的 **80%**；同时不得低于用人单位所在地的最低工资标准。（第 20 条）

## 三、用人单位以"不符合录用条件"解除的要件

必须**同时**满足以下四项：

1. **存在合法有效的试用期约定** —— 期限未超上限、且非禁止约定试用期的情形；
2. **录用条件已经明确并告知劳动者** —— 有书面文件且经劳动者签收；
3. **不符合录用条件有客观可验证的依据** —— 标准应当可量化、可举证；
4. **解除行为在试用期内完成** —— 解除通知须在试用期届满前送达劳动者。

**实务中最集中的败诉原因是第 2 项与第 4 项**：录用条件未书面化签收，或解除通知迟于试用期届满。

另需注意：用人单位在试用期解除劳动合同，**应当向劳动者说明理由**（第 21 条）。

## 四、劳动者在试用期的权利

- 提前 **3 日**通知即可解除劳动合同（第 37 条），无需说明理由；
- 试用期包含在劳动合同期限内，用人单位应**依法缴纳社会保险**；
- 试用期工资不低于前述法定底线。

## 五、需要纠正的常见认知

| 常见说法 | 正确认识 |
|---|---|
| 试用期不用签书面合同 | 必须签；未签同样产生二倍工资责任 |
| 试用期不用缴社保 | 应当缴纳，试用期包含在合同期内 |
| 试用期解除一律无补偿 | 符合第 39 条的过错性解除无补偿；但要件不具备即构成违法解除，需按第 87 条支付 2 倍赔偿金 |
| 试用期内可以随时辞退 | 试用期解除同样受法定条件约束，只是认定标准低于转正后 |
| 先试用一段时间再签合同 | 该做法本身违法，且所谓"试用期"不成立 |

## 六、签约前自查（用人单位）

- [ ] 试用期长度与合同期限是否匹配？
- [ ] 录用条件是否已书面化并完成签收？
- [ ] 考核标准是否可量化、可举证？
- [ ] 解除流程是否确保通知在试用期届满前送达？
- [ ] 试用期工资是否不低于法定下限？
- [ ] 试用期社会保险是否已依法缴纳？

## 七、签约前自查（劳动者）

- [ ] 试用期长度与你的合同期限是否匹配？
- [ ] 试用期工资是多少，是否低于法定下限？
- [ ] 是否清楚自己的录用条件和考核标准？
- [ ] 合同是否写明转正后的具体薪酬数额？
- [ ] 入职后是否查到社保缴纳记录？

> `[地方差异]` 三地对试用期解除的举证要求、违法解除的处理口径存在差异，涉及争议时按城市分别判断。
