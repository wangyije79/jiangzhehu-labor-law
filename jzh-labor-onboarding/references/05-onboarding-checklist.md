# 入职材料与签收留存清单

> **依据**：《劳动合同法》第 8、9、10、17、39 条及相关实务要求。本文件为独立编写。

> **核心逻辑**：入职环节的每一份文件，本质上都是在为未来可能发生的争议建立证据基础。当下缺失的凭证，在争议发生时无法补造。

## 一、用人单位应当收取并留存

| 材料 | 作用 | 留存要求 |
|---|---|---|
| 身份证件原件核验 + 复印件 | 确认身份真实性 | 复印件由劳动者签署"与原件一致"并注明日期 |
| 学历、职业资格材料核验 + 复印件 | 核实入职资格 | 同上 |
| **离职证明** | 避免招用尚未解除劳动关系人员导致连带赔偿责任 | 收取原件归档 |
| 入职体检报告 | 岗位适配性与职业禁忌筛查 | 注意个人信息保护，依法定范围收集 |
| **背景调查授权书** | 合法开展背景调查的前提 | 书面签字，明确授权范围与用途 |
| **录用条件确认书** | 试用期以"不符合录用条件"解除的举证基础 | 劳动者签收，条件应当具体可量化 |
| **规章制度签收单** | 规章制度对劳动者产生约束力的公示要件 | 签字并注明日期 |
| **告知义务确认书** | 证明已履行第 8 条告知义务 | 列明告知事项并签收 |
| 银行账户、紧急联系人信息 | 发薪与应急联系 | 按最小必要原则收集 |
| 劳动合同（一式两份） | — | 双方各持一份，不得全部由用人单位留存 |

## 二、劳动者应当自行留存

签字之后，务必确保自己手上有以下材料：

- [ ] **劳动合同原件**（用人单位不交付的，可向劳动保障监察机构投诉）
- [ ] 录用通知（纸质件或邮件原始记录）
- [ ] 录用条件确认书
- [ ] 员工手册或规章制度文本（至少留存影像件）
- [ ] 工资构成说明或薪资确认文件
- [ ] 考勤方式说明（打卡方式、排班规则、加班申请流程）

## 三、三种不宜签署的情形

1. **空白文本** —— 先签字后填写内容的，等于将解释空间完全让给对方。
2. **仅有一份且自己不留存** —— 至少应保留一份原件或清晰完整的影像件。
3. **与事先约定明显不一致** —— 例如沟通时约定月薪 15000 元、合同载明 5000 元，签署后主张推翻的难度显著上升。

## 四、背景调查的合法边界

合法开展背景调查需同时满足三个条件：

1. 取得被调查人的**书面授权**；
2. 调查范围限于**与应聘岗位直接相关的必要信息**（不得涉及婚姻生育状况、宗教信仰、与岗位无关的健康信息等）；
3. 信息来源与获取方式合法，**不得向无关第三方打探**。

**需特别注意的风险**：超出授权范围收集、或对获取的求职者个人信息进行转卖、提供，可能触及**侵犯公民个人信息**的刑事风险。

## 五、入职环节自查（用人单位）

- [ ] 用工满一个月前已完成书面合同签订？
- [ ] 录用条件已书面化并完成签收？
- [ ] 规章制度已履行公示告知程序并留存凭证？
- [ ] 已核验并归档离职证明？
- [ ] 背景调查已取得书面授权且范围适当？
- [ ] 社会保险已自用工之日起办理缴纳？
- [ ] 实习、返聘、劳务等特殊用工类型是否使用了对应协议？

## 六、入职环节自查（劳动者）

- [ ] 手上是否持有劳动合同原件？
- [ ] 是否清楚自己的录用条件与考核标准？
- [ ] 是否清楚工资的具体构成与各部分金额？
- [ ] 是否清楚考勤方式与加班申请流程？
- [ ] 试用期长度、试用期工资是否与合同期限匹配？
- [ ] 入职后是否核对过社保缴纳记录？
