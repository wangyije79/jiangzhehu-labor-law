# 检查表

## 材料与程序自查

- [ ] 是否在三十日内申报工伤认定
- [ ] 停工留薪期是否有医疗证明支撑
- [ ] 停工留薪期工资是否按原待遇发放
- [ ] 是否办理了劳动能力鉴定
- [ ] 按伤残等级应支付的补偿项目是否齐全
- [ ] 社保是否依法参保

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 引用案例是否标注了法院与年份
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 涉及个案争议时是否提示了咨询律师
