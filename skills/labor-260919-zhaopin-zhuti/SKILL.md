# 招聘主体与背景调查

> 如实告知义务、押金证件禁区与背调边界

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「面试时公司没说实话，能反悔吗？」「入职收押金扣证件违法吗？」

**什么时候会用到它**：

- 面试时公司没说实话，能反悔吗
- 入职收押金扣证件违法吗
- 背景调查能查到什么程度

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

## 二、装完验证（确认真生效）

在对话里问一句测试问题：

```
面试时公司没说实话，能反悔吗？
```

**验证标准**：回答应当**先区分情形**（不同情形结论不同），再给出对应的法律依据（法规名 + 条号）。
如果它直接给一个笼统结论、不区分情形，说明技能没被正确加载，请检查技能目录是否放在正确位置。

再测一句越界问题「帮我起草一份起诉状」——期望它说明本技能只提供一般性知识、不代拟正式文书。
若它直接开始写文书，同样说明技能未生效。

## 三、适用边界（什么时候别用它）

- **地域**：本技能以中国大陆法律为基础，案例与操作口径侧重上海、江苏、浙江。其他地区裁审尺度可能不同。
- **时间**：法条核验日期见 `references/law.md` 页首，法律修订后需重新核验。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非劳动法问题**：劳动合同、工时休假、社保工伤、解除终止以外的领域（如股权、知识产权、刑事）不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、代理词等正式法律文书。

## 四、适用范围

适用于企业招聘与入职环节的合规管理，也适用于求职者判断公司行为是否越界。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 公司招人时没说明真实工作内容 | 是否属于法定应告知事项（工作内容、条件、地点、职业危害、安全状况、劳动报酬） | 属于法定告知范围，未如实告知的可能影响合同效力，员工可主张相应权利 |
| 公司要求交押金、扣押证件 | 是否属于法律禁止的担保或收费行为 | 法律明确禁止，用人单位将面临责令退还、罚款等后果 |
| 公司要做背景调查 | 调查范围是否限于与劳动合同直接相关的基本情况 | 超出必要范围、未取得本人同意的调查可能侵犯个人信息权益 |
| 背景调查委托第三方机构 | 是否履行了告知与同意程序 | 需取得本人同意，并确保第三方合规处理个人信息 |

## 六、操作步骤

1. 面试环节书面告知：将工作内容、条件、地点、职业危害、报酬等做成告知清单并签字
2. 严禁收取财物：不得以任何名义收押金、保证金、培训费，不得扣押证件原件
3. 背调前置同意：入职前取得书面授权，明确调查范围与用途
4. 背调范围收窄：只查与岗位履职直接相关的经历与资质
5. 资料留存：告知清单、授权书、背调报告一并归档

## 七、常见误区

- 口头说明工作内容，事后无法证明已告知
- 以「培训费」「服装费」等名义变相收费
- 扣押身份证、学历证原件
- 背调不告知本人，或扩大到家庭、婚育等无关信息

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **案例要标地域**：引用案例时说明法院与年份，地域限于上海、江苏、浙江，见 `references/cases.md`。
5. **缺材料不猜**：使用者未提供的关键事实（如入职时间、合同约定、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体赔偿金额、不替代正式法律意见。

## 九、输出格式

回答时按以下结构组织：

- **结论**：一句话给出判断
- **依据**：涉及的法条（法规名 + 条号）
- **理由**：为什么这样判断，结合使用者提供的事实
- **建议动作**：下一步该做什么，需要准备什么材料
- **风险提示**：哪些环节容易出问题，需要特别注意

## 关于专业咨询

本技能包提供的是**一般性法律知识**，用于帮助使用者理解规则、判断方向、准备材料。

法律适用高度依赖具体事实与证据。以下情形建议咨询执业律师：

- 涉及金额较大或可能进入仲裁、诉讼的争议
- 事实复杂、证据不足或对方已委托律师
- 需要在多个方案之间做取舍，或需要出具正式法律文书
- 对时效、管辖、程序节点把握不准
