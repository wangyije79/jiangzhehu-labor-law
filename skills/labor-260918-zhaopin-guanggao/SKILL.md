# 招聘广告合规

> 招聘广告的法律效力、歧视禁区与录用条件设计

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「招聘广告写低了工资，入职能反悔吗？」「招聘广告能不能写性别年龄限制？」

**什么时候会用到它**：

- 招聘广告写低了工资，入职能反悔吗
- 招聘广告能不能写性别年龄限制
- 招聘条件写太细会不会变成录用条件

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

## 二、装完验证（确认真生效）

在对话里问一句测试问题：

```
招聘广告写低了工资，入职能反悔吗？
```

**验证标准**：回答应当**先区分情形**（不同情形结论不同），再给出对应的法律依据（法规名 + 条号）。
如果它直接给一个笼统结论、不区分情形，说明技能没被正确加载，请检查技能目录是否放在正确位置。

再测一句越界问题「帮我起草一份起诉状」——期望它说明本技能只提供一般性知识、不代拟正式文书。
若它直接开始写文书，同样说明技能未生效。

## 三、适用边界（什么时候别用它）

- **地域**：本技能以中国大陆法律为基础，案例与操作口径侧重上海、江苏、浙江。其他地区裁审尺度可能不同。
- **时间**：法条核验日期见 `references/law.md` 页首，法律修订后需重新核验。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非劳动法问题**：劳动合同、工时休假、社保工伤、解除终止以外的领域（如股权、知识产权、刑事）不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、代理词等正式法律文书。

## 四、适用范围

适用于企业招聘环节的广告发布与文案审核，也适用于求职者判断招聘信息是否可信、入职后发现待遇与广告不符时如何主张。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 招聘广告写了具体待遇，入职却不一样 | 广告内容是否具体明确（有明确数额或标准）且求职者据此入职 | 广告原则上属要约邀请，一般无约束力；但内容具体明确、求职者基于合理信赖入职的，可能被认定为录用条件的一部分，公司需承担相应责任 |
| 广告写了性别、年龄、户籍等限制 | 该限制是否属于岗位真实职业资格所必需 | 不属于真实职业资格的，构成就业歧视，可能面临行政处罚与赔偿责任 |
| 广告承诺的待遇与劳动合同不一致 | 以哪份文件为准 | 以劳动合同约定为准；但广告中的虚假承诺可能构成欺诈，员工可主张相应权利 |
| 招聘条件写得非常具体 | 是否可能被认定为录用条件 | 条件越具体越容易被认定为录用条件，公司据此解除时举证责任反而更重 |

## 六、操作步骤

1. 发布前审核文案：删去性别、婚育、户籍、年龄（非必要）等歧视性表述
2. 待遇表述留有余地：写明构成、浮动区间与确定方式，避免单一确定数额
3. 区分两类文件：招聘广告对外、录用条件对内，分别成文并各自留档
4. 录用条件书面化：录用通知书或岗位说明中写明考核指标与不合格标准
5. 保留沟通记录：面试记录、录用通知、员工签收记录一并归档

## 七、常见误区

- 把招聘广告当成正式承诺，写死具体数额却不兑现
- 以为招聘广告没有约束力，于是随意夸大
- 招聘条件写得过细，反被认定为录用条件
- 广告与劳动合同待遇不一致，未做衔接说明

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **案例要标地域**：引用案例时说明法院与年份，地域限于上海、江苏、浙江，见 `references/cases.md`。
5. **缺材料不猜**：使用者未提供的关键事实（如入职时间、合同约定、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体赔偿金额、不替代正式法律意见。

## 九、输出格式

回答时按以下结构组织：

- **结论**：一句话给出判断
- **依据**：涉及的法条（法规名 + 条号）
- **理由**：为什么这样判断，结合使用者提供的事实
- **建议动作**：下一步该做什么，需要准备什么材料
- **风险提示**：哪些环节容易出问题，需要特别注意
