# 检查表

## 材料与程序自查

- [ ] 招聘广告文案是否已通过歧视性表述审查
- [ ] 待遇表述是否写明构成与确定方式
- [ ] 录用条件是否单独成文并有员工签收
- [ ] 面试记录是否留存（含告知内容）
- [ ] 录用通知书与劳动合同的待遇表述是否一致

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 引用案例是否标注了法院与年份
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 涉及个案争议时是否提示了咨询律师
