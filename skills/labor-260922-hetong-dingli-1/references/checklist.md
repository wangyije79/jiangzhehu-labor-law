# 检查表

## 材料与程序自查

- [ ] 签约人是否为公司法定代表人或持授权委托书
- [ ] 员工是否达到法定劳动年龄、是否已享受养老待遇
- [ ] 合同类型选择是否有合理依据
- [ ] 九项必备条款是否齐全
- [ ] 空白条款是否已划线封口
- [ ] 员工是否签收了自己那一份合同

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 引用案例是否标注了法院与年份
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 涉及个案争议时是否提示了咨询律师
