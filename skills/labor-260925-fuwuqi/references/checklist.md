# 检查表

## 材料与程序自查

- [ ] 培训是否属于专业技术培训并有培训方案
- [ ] 培训费用是否有支付凭证
- [ ] 培训费用是否分项列明
- [ ] 违约金是否约定按未履行部分分摊
- [ ] 培训协议是否与劳动合同同步签署
- [ ] 工资社保是否被错误计入培训费用

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 引用案例是否标注了法院与年份
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 涉及个案争议时是否提示了咨询律师
