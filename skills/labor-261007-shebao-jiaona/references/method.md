# 分析框架与操作方法

## 判断逻辑

### 节点 1：试用期要不要缴社保

- **判断标准**：是否已建立劳动关系
- **处理结论**：自用工之日起三十日内应办理社保登记，试用期不是免缴期

### 节点 2：社保基数能不能按最低缴

- **判断标准**：员工实际工资水平
- **处理结论**：应按本人上年度月平均工资确定，低于下限按下限，高于上限按上限

### 节点 3：员工自愿放弃社保是否有效

- **判断标准**：是否属于可处分的权利
- **处理结论**：社保是国家强制保险，缴费义务不能通过约定免除，承诺书无效

### 节点 4：未缴社保有什么后果

- **判断标准**：用人单位与员工各自面临什么风险
- **处理结论**：用人单位面临补缴、滞纳金、罚款；员工可据此主张被迫解除并要经济补偿

## 操作步骤

1. 入职当月即办理参保，不等到转正
2. 按实际工资申报基数，每年核对调整
3. 员工拒绝提供的，书面告知参保是法定义务
4. 发现历史未缴的，主动核算并申报补缴
5. 建立社保台账，每月核对缴费明细

## 常见误区

- 认为试用期不用缴社保
- 按最低基数缴纳以节省成本
- 接受员工自愿放弃社保的承诺书
- 发现历史欠缴后拖延不处理

## 说明

社保是强制性义务，没有协商空间。按实际工资及时参保，是成本最低、风险最小的做法。
