# 检查表

## 材料与程序自查

- [ ] 解除是否有法定事由支撑
- [ ] 是否事先通知工会并留存记录
- [ ] 解除通知是否写明依据与事实
- [ ] 送达方式是否合法并留有凭证
- [ ] 是否出具离职证明并办理转移
- [ ] 是否结清工资与经济补偿

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 引用案例是否标注了法院与年份
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 涉及个案争议时是否提示了咨询律师
