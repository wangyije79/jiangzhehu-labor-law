# 检查表

## 材料与程序自查

- [ ] 制度是否经民主程序并公示
- [ ] 制度是否明确该行为属严重违纪
- [ ] 是否有客观证据证明违纪事实
- [ ] 谈话笔录是否有员工签字
- [ ] 是否事先通知工会
- [ ] 解除通知是否写明具体事由与依据
- [ ] 送达是否有凭证

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 引用案例是否标注了法院与年份
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 涉及个案争议时是否提示了咨询律师
