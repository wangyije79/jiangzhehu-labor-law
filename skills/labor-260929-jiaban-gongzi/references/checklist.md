# 检查表

## 材料与程序自查

- [ ] 合同或制度是否明确约定加班费计算基数
- [ ] 基数是否明显低于正常工资水平
- [ ] 加班审批流程是否实际执行
- [ ] 考勤记录是否完整保存
- [ ] 值班与加班是否在制度中区分
- [ ] 加班费是否在工资清单中单列

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 引用案例是否标注了法院与年份
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 涉及个案争议时是否提示了咨询律师
