# 竞业限制实操

> 竞业限制的解除、违约金与报告义务

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「公司想提前解除竞业限制怎么办？」「竞业违约金约定两倍支持吗？」

**什么时候会用到它**：

- 公司想提前解除竞业限制怎么办
- 竞业违约金约定两倍支持吗
- 离职不说新东家算违约吗

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

## 二、装完验证（确认真生效）

在对话里问一句测试问题：

```
公司想提前解除竞业限制怎么办？
```

**验证标准**：回答应当**先区分情形**（不同情形结论不同），再给出对应的法律依据（法规名 + 条号）。
如果它直接给一个笼统结论、不区分情形，说明技能没被正确加载，请检查技能目录是否放在正确位置。

再测一句越界问题「帮我起草一份起诉状」——期望它说明本技能只提供一般性知识、不代拟正式文书。
若它直接开始写文书，同样说明技能未生效。

## 三、适用边界（什么时候别用它）

- **地域**：本技能以中国大陆法律为基础，案例与操作口径侧重上海、江苏、浙江。其他地区裁审尺度可能不同。
- **时间**：法条核验日期见 `references/law.md` 页首，法律修订后需重新核验。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非劳动法问题**：劳动合同、工时休假、社保工伤、解除终止以外的领域（如股权、知识产权、刑事）不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、代理词等正式法律文书。

## 四、适用范围

适用于企业设计竞业限制条款、处理员工离职后的竞业管理，也适用于员工判断竞业义务边界。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 公司想提前解除竞业限制 | 是否已书面通知并支付额外补偿 | 用人单位可单方解除，但需额外支付三个月补偿；未通知的，员工可主张继续履行并索要补偿 |
| 违约金约定为补偿金的两倍 | 约定数额是否与实际损失相当 | 约定有效但过高的，法院可依当事人请求予以适当减少 |
| 员工离职后未报告新单位 | 是否违反竞业义务 | 未报告不等于违反竞业义务；需看是否实际入职竞争单位 |
| 竞业限制是否适用于该员工 | 是否属于高级管理人员、高级技术人员或其他负有保密义务的人员 | 不适用的人员签订竞业限制条款的，条款可能被认定无效 |

## 六、操作步骤

1. 确定适用对象：限于确有保密必要的人员，不搞全员套餐
2. 约定核心要素：范围、地域、期限（不超过二年）、补偿标准、违约责任
3. 按月支付补偿：离职后按月支付，避免一次性预付引发争议
4. 解除要留痕：提前解除的书面通知送达并留存，同时支付额外补偿
5. 离职面谈确认：明确竞业范围与报告义务，形成书面确认

## 七、常见误区

- 对全员签竞业协议，导致条款被认定无效
- 离职后不支付补偿，却要求员工履行竞业义务
- 把「未报告新单位」直接等同于违反竞业义务
- 违约金定得过高，最终被法院大幅调减

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **案例要标地域**：引用案例时说明法院与年份，地域限于上海、江苏、浙江，见 `references/cases.md`。
5. **缺材料不猜**：使用者未提供的关键事实（如入职时间、合同约定、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体赔偿金额、不替代正式法律意见。

## 九、输出格式

回答时按以下结构组织：

- **结论**：一句话给出判断
- **依据**：涉及的法条（法规名 + 条号）
- **理由**：为什么这样判断，结合使用者提供的事实
- **建议动作**：下一步该做什么，需要准备什么材料
- **风险提示**：哪些环节容易出问题，需要特别注意
