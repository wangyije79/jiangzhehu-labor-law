# 检查表

## 材料与程序自查

- [ ] 竞业对象是否属于法定适用人员范围
- [ ] 竞业期限是否超过二年
- [ ] 补偿标准是否明确并按月支付
- [ ] 违约金是否与实际损失相匹配
- [ ] 解除竞业是否有书面通知与送达凭证
- [ ] 是否支付了额外三个月补偿

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 引用案例是否标注了法院与年份
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 涉及个案争议时是否提示了咨询律师
