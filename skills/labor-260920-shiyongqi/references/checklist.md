# 检查表

## 材料与程序自查

- [ ] 试用期长度是否在法定上限内
- [ ] 是否只约定过一次试用期
- [ ] 试用期工资是否达到法定下限
- [ ] 录用条件是否书面化并有员工签收
- [ ] 考核记录是否完整并留有员工签字
- [ ] 解除通知是否写明理由

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 引用案例是否标注了法院与年份
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 涉及个案争议时是否提示了咨询律师
