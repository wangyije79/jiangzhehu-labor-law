# 检查表

## 材料与程序自查

- [ ] 提成规则是否书面化并送达员工
- [ ] 计算口径是否明确（签约额或回款额）
- [ ] 离职时未结算提成的处理是否有约定
- [ ] 年终奖性质与折算规则是否写明
- [ ] 是否按月提供工资清单
- [ ] 工资支付记录是否保存两年以上

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 引用案例是否标注了法院与年份
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 涉及个案争议时是否提示了咨询律师
