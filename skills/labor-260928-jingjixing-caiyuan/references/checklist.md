# 检查表

## 材料与程序自查

- [ ] 是否达到法定裁员门槛
- [ ] 是否属于四类法定情形并有证据支撑
- [ ] 说明会的通知、签到表、会议记录是否齐全
- [ ] 是否向劳动行政部门报送方案并有凭证
- [ ] 是否排除禁止解除的六种人员
- [ ] 是否做了优先留用人员比对
- [ ] 经济补偿是否依法计算并支付

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 引用案例是否标注了法院与年份
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 涉及个案争议时是否提示了咨询律师
