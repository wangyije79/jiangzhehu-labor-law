# 经济性裁员

> 裁员的法定情形、程序要件与禁止解除名单

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「裁员二十人以上要走什么程序？」「经营困难裁员为什么被判违法？」

**什么时候会用到它**：

- 裁员二十人以上要走什么程序
- 经营困难裁员为什么被判违法
- 哪些人裁员时不能动

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

## 二、装完验证（确认真生效）

在对话里问一句测试问题：

```
裁员二十人以上要走什么程序？
```

**验证标准**：回答应当**先区分情形**（不同情形结论不同），再给出对应的法律依据（法规名 + 条号）。
如果它直接给一个笼统结论、不区分情形，说明技能没被正确加载，请检查技能目录是否放在正确位置。

再测一句越界问题「帮我起草一份起诉状」——期望它说明本技能只提供一般性知识、不代拟正式文书。
若它直接开始写文书，同样说明技能未生效。

## 三、适用边界（什么时候别用它）

- **地域**：本技能以中国大陆法律为基础，案例与操作口径侧重上海、江苏、浙江。其他地区裁审尺度可能不同。
- **时间**：法条核验日期见 `references/law.md` 页首，法律修订后需重新核验。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非劳动法问题**：劳动合同、工时休假、社保工伤、解除终止以外的领域（如股权、知识产权、刑事）不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、代理词等正式法律文书。

## 四、适用范围

适用于企业实施规模性裁员的方案设计与程序执行，也适用于员工判断裁员是否合法。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 裁减人数达到门槛 | 是否达到二十人以上，或不足二十人但占职工总数百分之十以上 | 达到门槛的，必须走经济性裁员程序 |
| 是否符合法定情形 | 是否属于破产重整、生产经营严重困难、转产或经营方式调整、客观经济情况重大变化四类之一 | 不属于四类情形的，不能按经济性裁员处理 |
| 程序是否走完 | 是否提前三十日说明情况、听取意见、向劳动行政部门报告 | 任一环节缺失，可能被认定违法解除 |
| 哪些人不能裁 | 是否落入禁止解除的六种情形 | 落入的不得依第四十条、第四十一条解除，合同应续延至情形消失 |

## 六、操作步骤

1. 评估是否达到裁员门槛与法定情形
2. 制定裁减人员方案：名单、时间、步骤、补偿办法
3. 提前三十日向工会或全体职工说明并听取意见，形成书面记录
4. 将方案报送劳动行政部门并留存报送凭证
5. 排除禁止解除人员，比对优先留用人员
6. 实施裁员并支付经济补偿，六个月内重新招用应优先通知被裁人员

## 七、常见误区

- 向非劳动行政部门备案，被认定未完成报告义务
- 只发通知不开说明会，程序留有瑕疵
- 漏掉禁止解除人员，导致个别解除违法
- 把经营困难当理由，却拿不出财务证据

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **案例要标地域**：引用案例时说明法院与年份，地域限于上海、江苏、浙江，见 `references/cases.md`。
5. **缺材料不猜**：使用者未提供的关键事实（如入职时间、合同约定、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体赔偿金额、不替代正式法律意见。

## 九、输出格式

回答时按以下结构组织：

- **结论**：一句话给出判断
- **依据**：涉及的法条（法规名 + 条号）
- **理由**：为什么这样判断，结合使用者提供的事实
- **建议动作**：下一步该做什么，需要准备什么材料
- **风险提示**：哪些环节容易出问题，需要特别注意
