# 检查表

## 材料与程序自查

- [ ] 交接清单是否逐项签字确认
- [ ] 工资是否在解除或终止时一次付清
- [ ] 离职证明是否写明四项必备内容
- [ ] 是否在十五日内办理档案与社保转移
- [ ] 结算协议是否列明各项金额及计算过程
- [ ] 是否区分了交接单与结算协议

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 引用案例是否标注了法院与年份
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 涉及个案争议时是否提示了咨询律师
