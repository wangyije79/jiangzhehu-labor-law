# 江浙沪劳动法技能包

> 面向企业 HR、法务与劳动者的劳动法实务技能包，按主题逐日更新。
> 每个技能包可直接安装到 AI 编程助手（ZCode / Claude Code / Codex）使用。

作者：**王毅杰律师**（上海德禾翰通律师事务所）· 执业领域：劳动争议、企业用工合规

## 这是什么

一组可安装的 **AI 技能包**。装上之后，你就能就该主题提问，AI 会按包内的判断流程回答：
先区分你的情况属于哪一类，再给结论、法律依据（具体到法条条号）、建议动作和风险提示。

法条均逐字回权威库核验；案例地域限**上海、江苏、浙江**。

## 怎么用

**方式一 · AI 一键安装**（推荐）

把下面这句话发给你的 AI 助手：

```
把 https://github.com/wangyije79/jiangzhehu-labor-law 里 skills/<技能包名> 这个技能包装到当前目录
```

**方式二 · 手动安装**

下载对应目录，放进你的技能目录即可：

- ZCode：`~/.zcode/skills/`
- Claude Code：`~/.claude/skills/`

**方式三 · 在线读**

直接点表格里的链接，用法都在 `SKILL.md` 里。

## 数据与核验

- **法条**：经北大法宝（pkulaw）逐字核验，记录见各包的 `audit/legal-verification.json`
- **案例**：来自公开裁判文书检索，地域限上海、江苏、浙江
- **更新**：按主题持续更新，版本见各包 `manifest.yaml`
